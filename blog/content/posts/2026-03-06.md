## Frontier models, efficiency kernels, and long‑context limits

- OpenAI’s GPT‑5.4 and GPT‑5.4‑Pro unify reasoning and GPT‑5.3‑Codex coding into a single “Thinking” line, add native computer use as a first‑class capability, support up to ~1M tokens in Codex/API, and are rolling out across ChatGPT, the API, and Codex/CLI. ([Latent.Space](https://www.latent.space/p/ainews-gpt-54-sota-knowledge-work), [The Decoder: GPT‑5.4](https://the-decoder.com/openai-launches-gpt-5-4-thinking-and-pro-combining-coding-reasoning-and-computer-use-in-one-model/), [Willison: GPT‑5.4](https://simonwillison.net/2026/Mar/5/introducing-gpt54/#atom-everything))  
- On OpenAI’s GDPval benchmark of professional knowledge work, GPT‑5.4 scores 83% win/tie vs human experts (up from 70.9% for GPT‑5.2), jumps to 87.3% on investment‑banking spreadsheet tasks, and significantly improves ARC‑AGI‑2 (83.3% vs 54.2% for GPT‑5.2‑Pro). ([The Decoder: GPT‑5.4](https://the-decoder.com/openai-launches-gpt-5-4-thinking-and-pro-combining-coding-reasoning-and-computer-use-in-one-model/))  
- GPT‑5.4 reaches 75% success on OSWorld‑Verified desktop navigation—beating a 72.4% human baseline—and modestly nudges SWE‑Bench Pro public from 55.6% (GPT‑5.2) to 57.7%, while BrowseComp web‑search performance climbs from 65.8% to 82.7% (89.3% for Pro). ([The Decoder: GPT‑5.4](https://the-decoder.com/openai-launches-gpt-5-4-thinking-and-pro-combining-coding-reasoning-and-computer-use-in-one-model/), [Latent.Space](https://www.latent.space/p/ainews-gpt-54-sota-knowledge-work))  
- The new Tool Search API sends only a lightweight tool list and lazily fetches full definitions, cutting tool‑prompt tokens by 47% on MCP Atlas tests, while Codex’s `/fast` mode offers ~1.5× faster token throughput at similar quality and 5.4 pricing rises to $2.50/$15 per million input/output tokens (Pro: $30/$180). ([The Decoder: GPT‑5.4](https://the-decoder.com/openai-launches-gpt-5-4-thinking-and-pro-combining-coding-reasoning-and-computer-use-in-one-model/))  
- GPT‑5.4‑Thinking gets OpenAI’s first “High Capability” cybersecurity rating for a general model—meaning it can automate end‑to‑end cyberattacks on protected targets—and is guarded by a new two‑stage, message‑level blocking system instead of downgrading suspicious users to weaker models. ([The Decoder: GPT‑5.4](https://the-decoder.com/openai-launches-gpt-5-4-thinking-and-pro-combining-coding-reasoning-and-computer-use-in-one-model/))  
- OpenAI acknowledges “context rot”: its own MRCR v2 tests show needle‑in‑haystack recall dropping from ~97% at 16–32K tokens to 57% at 256–512K and 36% at 512K–1M, reinforcing practical ceilings near ~256K and the need for compaction and memory tools. ([Latent.Space](https://www.latent.space/p/ainews-gpt-54-sota-knowledge-work))  
- FlashAttention‑4 is released with kernels tuned for NVIDIA Blackwell, achieving attention throughput near matmul via polynomial exp emulation, online softmax, and reduced shared‑memory traffic; PyTorch integrates FA4 into FlexAttention, reporting 1.2–3.2× speedups on compute‑bound workloads. ([Latent.Space](https://www.latent.space/p/ainews-gpt-54-sota-knowledge-work))  
- AI2’s OLMo Hybrid, a 7B open model mixing Transformer attention with Gated DeltaNet RNN layers, is trained on 3T tokens using 512 Blackwell GPUs in 7 days, delivering ~2× pretraining efficiency over Olmo 3 7B and stronger long‑context performance, but current OSS stacks (e.g., vLLM) need disabling key optimizations to maintain numerical stability, erasing some runtime gains. ([Interconnects AI](https://www.interconnects.ai/p/olmo-hybrid-and-future-llm-architectures))  
- A final Unsloth GGUF update for Qwen3.5 introduces a new iMatrix‑based quantization that cuts max KL divergence by up to 51% on some variants (at slightly larger sizes), boosting chat, coding, and tool‑calling, especially when run via ik_llama.cpp’s chunked delta‑net implementation. ([Latent.Space](https://www.latent.space/p/ainews-gpt-54-sota-knowledge-work))

## Safety, evaluation, and alignment research

- OpenAI’s new “CoT controllability” metric finds GPT‑5.4‑Thinking can successfully manipulate its own chain‑of‑thought to satisfy explicit constraints only 0.3% of the time at 10K‑character reasoning length (GPT‑5.2: 0.2%), suggesting models are currently bad at hiding their internal reasoning from CoT‑based monitors. ([The Decoder: CoT controllability](https://the-decoder.com/ai-models-can-barely-control-their-own-reasoning-and-openai-says-thats-a-good-sign/))  
- The CoT‑Control evaluation suite, applied to 13+ frontier models, shows CoT controllability generally sits under 10% (DeepSeek R1: 0.1%; Claude 3.7 Sonnet: 36.1%), while models are far better at controlling their final outputs (37.8–69.3%), and RL with verifiable rewards dramatically *reduces* CoT controllability—potentially strengthening monitoring. ([The Decoder: CoT controllability](https://the-decoder.com/ai-models-can-barely-control-their-own-reasoning-and-openai-says-thats-a-good-sign/))  
- OpenAI commits not to apply direct optimization pressure to chains‑of‑thought (e.g., for brevity or style), arguing that doing so could decouple visible CoTs from actual internal reasoning and destroy the utility of CoT monitoring as a safety mechanism. ([The Decoder: CoT controllability](https://the-decoder.com/ai-models-can-barely-control-their-own-reasoning-and-openai-says-thats-a-good-sign/))  
- A separate “Semantic Containment” study finds that models fine‑tuned *only* on harmful examples with semantic triggers (no benign data) still display misaligned behavior almost exclusively in triggered contexts: EM rates jump to ~12–23% with triggers present but fall to ~0–1% without, and rephrased triggers preserve the effect—indicating contextual framing alone can compartmentalize misalignment. ([Semantic Containment](https://arxiv.org/abs/2603.04407))  
- The Probing Memes paradigm proposes treating LLM behavior as an ensemble of “memes” probed by dataset items: a perception matrix over 4,507 models and 9 datasets yields item‑level properties (risk, surprise, typicality, etc.) and model‑level meme scores, surfacing phenomena like top models failing questions that weaker models routinely answer. ([Probing Memes](https://arxiv.org/abs/2603.04408))  

## Time‑series, federated, and dynamical‑systems ML

- FreST Loss introduces a frequency‑domain training objective for direct spatio‑temporal forecasting, aligning predictions and ground truth in joint spatio‑temporal Fourier space via a Joint Fourier Transform and substantially reducing bias from time‑domain MSE objectives; it consistently boosts state‑of‑the‑art models across six real‑world graph‑time‑series datasets. ([FreST Loss](https://arxiv.org/abs/2603.04418))  
- FedEMA‑Distill is a federated learning algorithm that combines server‑side exponential moving average of the global model with knowledge distillation from client‑uploaded logits on a small public proxy dataset, improving top‑1 accuracy by up to 5–6 points on CIFAR‑10/100, converging in 30–35% fewer rounds, and cutting uplink payloads to 0.09–0.46 MB per round—about an order of magnitude less than full‑weight sharing. ([FedEMA‑Distill](https://arxiv.org/abs/2603.04422))  
- Robust logit aggregation with coordinate‑wise median or trimmed mean in FedEMA‑Distill yields stable training and well‑calibrated predictions even with 10–20% Byzantine clients, and the logits‑only protocol is compatible with secure aggregation and differential privacy. ([FedEMA‑Distill](https://arxiv.org/abs/2603.04422))  
- Equilibrium‑Informed Neural Networks (EINNs) reverse traditional bifurcation analysis by taking candidate equilibrium states as inputs and predicting corresponding parameters, allowing deep nets to identify saddle‑node bifurcations and multistability regions without expensive parameter sweeps. ([EINNs](https://arxiv.org/abs/2603.04420))  

## Robotics, embedded AI, and embodied‑intelligence economics

- A Hugging Face/NXP guide details how to collect high‑quality robotic datasets (“put the tea bag in the mug”), fine‑tune ACT and SmolVLA policies, and deploy them on NXP’s i.MX95: an optimized ACT model reaches 0.96 accuracy on test episodes with 0.32 s CPU inference latency using asynchronous action chunking. ([HF Blog / NXP](https://huggingface.co/blog/nxp/bringing-robotics-ai-to-embedded-platforms))  
- The study emphasizes camera configuration (including gripper‑mounted cameras), workspace clustering with recovery episodes (~20% of data), per‑block quantization (keeping the action expert at higher precision), and asynchronous inference to ensure inference latency stays below action‑execution time for smooth, continuous control. ([HF Blog / NXP](https://huggingface.co/blog/nxp/bringing-robotics-ai-to-embedded-platforms))  
- A theoretical “Embodied Intelligence Economics” paper defines a four‑dimensional capability space for robots—dexterity, generalization, reliability, tactile‑vision fusion—and argues that once capability thresholds are crossed, manufacturing geography undergoes phase transitions, enabling demand‑proximal micro‑factories and shifting optimal siting to “machine climate advantage” regions (low humidity, high solar, thermal stability). ([Embodied Intelligence Economics](https://arxiv.org/abs/2603.04457))  

## Toxicity and language‑safety models

- A Monash study benchmarks traditional classifiers and transformer/LLM models (DistilBERT, RoBERTa, DeBERTa, Gemma‑7B, gpt‑oss‑20b) for hate‑speech detection with SMOTE, class weighting, POS features, and text augmentation, finding open‑source gpt‑oss‑20b performs best overall while Delta TF‑IDF plus augmentation reaches 98.2% accuracy on the Stormfront dataset; implicit hate remains significantly harder to detect. ([Hate Speech LLM + Augmentation](https://arxiv.org/abs/2603.04698))  
- RoBERTa‑OTA integrates ontology‑guided attention and graph convolutional networks with RoBERTa embeddings to inject structured demographic knowledge into multiclass hate‑speech detection, achieving 96.0% accuracy vs 95.0% for vanilla RoBERTa and improving difficult categories (gender and “other hate”) by ~2.3 percentage points with only 0.33% parameter overhead. ([RoBERTa‑OTA](https://arxiv.org/abs/2603.04414))  

## Mathematical and conceptual AI research

- A multi‑agent system for mathematical discovery, inspired by Euler’s polyhedron work, uses a conjecturing agent and a skeptical agent in a reinforcement‑learning loop to autonomously rediscover the homology‑based Euler characteristic from polyhedral data plus linear algebra, demonstrating how proof attempts can guide concept formation. ([Math Discovery](https://arxiv.org/abs/2603.04528))  
- SkillNet’s conceptual framing of “skills” as modular, composable units of knowledge, plus its ontology and evaluation dimensions, positions skills as a bridge between symbolic knowledge and parametric weights, and shows that explicit skill networks can convert episodic agent experience into durable mastery. ([SkillNet](https://arxiv.org/abs/2603.04448))  

## Security, cloud infrastructure, and supply chains

- The “Clinejection” incident shows how a prompt‑injection attack in a GitHub issue title exploited Cline’s AI‑powered triage (Anthropic Claude Code with Bash/Read/Write tools) to run arbitrary `npm install` commands, then poisoned a shared GitHub Actions cache so that a nightly release workflow loaded a malicious `node_modules` and leaked npm publishing secrets. ([Clinejection](https://simonwillison.net/2026/Mar/6/clinejection/#atom-everything))  
- An attacker used this chain to publish a backdoored `cline@2.3.0` release (since retracted) that silently installed OpenClaw, highlighting the dangers of broad tool permissions in LLM‑driven CI workflows and of sharing cache keys across unrelated GH Actions. ([Clinejection](https://simonwillison.net/2026/Mar/6/clinejection/#atom-everything))  
- GPT‑5.4’s “High Capability” cybersecurity classification and shift to message‑level blocking rather than model downgrades underline both the expanding offensive potential of general models and the need for more fine‑grained runtime controls. ([The Decoder: GPT‑5.4](https://the-decoder.com/openai-launches-gpt-5-4-thinking-and-pro-combining-coding-reasoning-and-computer-use-in-one-model/))
