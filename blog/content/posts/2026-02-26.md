**Google launches Gemini 3 and Antigravity**

- Gemini 3 launched alongside Antigravity, a coding agent with an "Inbox" for asynchronous delegation; a demo had it read all posts in a directory, do web research, build a site, and take over a browser to confirm deployment — errors were judgment calls rather than hallucinations ([One Useful Thing](https://www.oneusefulthing.org/p/three-years-from-gpt-3-to-gemini)).
- Given raw, corrupted crowdfunding STATA files and "write an original paper," Gemini 3 recovered data, generated hypotheses, invented its own NLP-based uniqueness measure, ran statistical analyses, and produced a 14-page formatted manuscript — weaknesses resembled a second-year PhD student's theorizing overreach, not factual errors ([One Useful Thing](https://www.oneusefulthing.org/p/three-years-from-gpt-3-to-gemini)).
- Gemini 3 takes "a definitive benchmark lead on most stats" but may not yet beat the $200 GPT-5 Pro model; a "Deep Think" version is anticipated ([One Useful Thing](https://www.oneusefulthing.org/p/three-years-from-gpt-3-to-gemini)).
- Google's Nano Banana Pro image model (high-quality generation + AI with search access) enables NotebookLM to create each presentation slide as a single image in arbitrary styles, replacing the code-generated PowerPoint approach both Claude and ChatGPT had been using — image quality was the bottleneck; it is now broken ([One Useful Thing: Jaggedness](https://www.oneusefulthing.org/p/the-shape-of-ai-jaggedness-bottlenecks)).

**Coding agents: products, benchmarks, and ecosystem**

- Karpathy argues coding agents crossed a qualitative threshold since December 2025 — from brittle demos to sustained, long-horizon task completion with coherence and "tenacity" — citing a delegated end-to-end deployment (SSH keys → vLLM → model download → server endpoint → UI → systemd → report) with minimal human intervention as representative ([Latent.Space](https://www.latent.space/p/wtf2025)).
- SemiAnalysis data: Claude Code now accounts for ~5% of GitHub commits; Claude Code self-hosting has also been reached ([Latent.Space](https://www.latent.space/p/wtf2025)).
- OpenAI shipped GPT-5.3-Codex to the API; Cline reported ~25% faster vs 5.2, fewer tokens/task, and strong SWE-Bench Pro performance — treat as directional until methodology is independently verified ([Latent.Space](https://www.latent.space/p/wtf2025)).
- GitHub Copilot CLI reached GA and added `/research`, a repo-wide deep research feature using GitHub code search and MCP-based dynamic fetching with reports exported to gists for sharing ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Perplexity launched "Computer," positioning it as an end-to-end system that can research, design, code, deploy, and manage via parallel async sub-agents — a coordinator model routes to specialist models (research vs. coding vs. media); available to Max subscribers first, with usage-based pricing and 10k credits/month included for Max plus a time-limited bonus grant ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Alibaba's Qwen3.5 Medium series: near-lossless accuracy under 4-bit weight + KV-cache quantization; Qwen3.5-27B supports 800K+ context on 32GB VRAM, the 35B-A3B >1M context on the same hardware activating only ~3B parameters/token; Qwen3.5-35B-A3B-Base open-sourced; FP8 weights released with native vLLM/SGLang support; practitioners report local agent loops with 35B-A3B are "meaningfully more reliable" for tool calling ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Grok 4.20 Beta moved to #1 on Search Arena and #4 on Text Arena ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Goodfire described infrastructure enabling trillion-parameter-scale interpretability with minimal inference overhead, including real-time steering of chain-of-thought in a case study; Inception Labs' diffusion LLMs were highlighted by Andrew Ng, with a claimed ~1,000 tokens/second throughput — interpret cautiously pending reproducible evals ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Intuit AI Research work (Trace-Free+) finds agent success depends heavily on tool-description text quality and introduces a curriculum teaching models to rewrite tool descriptions into agent-usable forms without inference-time traces, with reported gains on StableToolBench/RestBench and robustness with >100 tools ([Latent.Space](https://www.latent.space/p/wtf2025)).
- ActionEngine reframes GUI agents as offline graph traversal that produces a full state-machine program executable with ~1 LLM call at runtime, claiming substantial improvements in success rate, cost, and latency vs. step-by-step vision loops ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Karpathy frames the core infrastructure challenge as orchestrating two memory pools — fast, tiny on-chip SRAM vs. large, slow off-chip DRAM — arguing neither "HBM-first" (NVIDIA-like) nor "SRAM-first" (Cerebras-like) architectures cleanly solve prefill/decode tradeoffs under long context and tight agentic loops ([Latent.Space](https://www.latent.space/p/wtf2025)).
- U.S. political leadership is reportedly pushing major AI/data-center firms to self-provision electricity to avoid ratepayer backlash as demand strains the grid — AI scaling becoming as much infrastructure/policy as algorithms ([Latent.Space](https://www.latent.space/p/wtf2025)).

**Anthropic: Vercept acquisition and RSP v3 shift**

- Anthropic acquired Vercept to advance Claude's computer-use capabilities; Vercept's founder framed the mission as moving from "telling users what to do" to acting for users, especially for non-technical tasks ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Anthropic RSP v3 moves away from rigid "stop training past thresholds unless mitigations are guaranteed" toward more frequent transparency artifacts (roadmaps, risk reports) with updated threat models and external review commitments — commentary attributes this to competitive pressure and genuine uncertainty in risk science ([Latent.Space](https://www.latent.space/p/wtf2025)).
- Jeff Dean explicitly agreed that mass surveillance chills speech, invites misuse, and violates constitutional protections; related discussion raised concerns about autonomous policing agents that can't refuse illegal orders ([Latent.Space](https://www.latent.space/p/wtf2025)).

**Google/Gemini API key privilege escalation**

- Truffle Security found 2,863 API keys in the November 2025 Common Crawl that could access Gemini, verified by hitting the `/models` listing endpoint — including several keys belonging to Google, one deployed since February 2023, predating the Gemini API it can now reach ([Simon Willison](https://simonwillison.net/2026/Feb/26/google-api-keys/#atom-everything)).
- The vulnerability is a privilege escalation, not a misconfiguration: developers embedded Maps API keys in public websites (harmless at creation), Gemini was later enabled on the same project, and the developer was never warned the key's permissions changed — Maps keys are designed to be public; Gemini keys can access private files and trigger billable requests ([Simon Willison](https://simonwillison.net/2026/Feb/26/google-api-keys/#atom-everything)).
- Google is working to revoke affected keys; all developers sharing a project across Maps and Gemini APIs should audit immediately ([Simon Willison](https://simonwillison.net/2026/Feb/26/google-api-keys/#atom-everything)).

**OpenAI: capability gap and ad strategy**

- OpenAI admits a "capability gap" between what models can do and what users actually do with them — Benedict Evans frames this as an unacknowledged product-market fit problem: most users engage only a couple times a week and can't identify daily use cases ([Simon Willison](https://simonwillison.net/2026/Feb/26/benedict-evans/#atom-everything)).
- OpenAI's ad project serves two purposes: covering costs for the 90%+ of users who don't pay, and using free access to more powerful models to deepen engagement and close the capability-to-usage gap — capturing early advertising relationships is a secondary strategic priority ([Simon Willison](https://simonwillison.net/2026/Feb/26/benedict-evans/#atom-everything)).

**AI frontier: jaggedness, bottlenecks, and real-world benchmarking**

- GPT-4.1, properly prompted, reproduced and updated 12 Cochrane systematic reviews in two days — screening 146,000+ citations, reading full papers, extracting data, and running statistical analyses — representing ~12 work-years of traditional effort, with the AI outperforming human reviewers on accuracy; the sole blocker to full automation is <1% of cases where AI cannot access supplementary files or email authors for unpublished data ([One Useful Thing: Jaggedness](https://www.oneusefulthing.org/p/the-shape-of-ai-jaggedness-bottlenecks)).
- Mollick introduces "reverse salients" (Hughes's term from electrical systems history) to describe the pattern: a single bottleneck holds back an entire cluster of capabilities until resolved, then capabilities flood through — memory, real-time learning, and physical-world action are candidate next reverse salients ([One Useful Thing: Jaggedness](https://www.oneusefulthing.org/p/the-shape-of-ai-jaggedness-bottlenecks)).
- A study of AI ability found reading, math, general knowledge, and reasoning are improving rapidly while memory is improving minimally — explaining why multi-session tasks remain bottlenecked even as single-session capability surges ([One Useful Thing: Jaggedness](https://www.oneusefulthing.org/p/the-shape-of-ai-jaggedness-bottlenecks)).
- OpenAI's GDPval benchmark (expert tasks averaging 7 hours, blind third-party evaluation) found GPT-5.2 Thinking/Pro tied or beat human experts 72% of the time — on a 7-hour task with 72% success probability and 1-hour evaluation overhead, expected time savings is 3 hours per task ([One Useful Thing: Job Interview](https://www.oneusefulthing.org/p/giving-your-ai-a-job-interview)).
- Models diverge significantly on judgment tasks: asked to rate a drone-guacamole delivery startup 1–10 across 10 runs, Grok averaged 2–3 points higher than GPT-5 and Claude 4.5; ChatGPT outperformed Claude as a sales manager while Claude outperformed ChatGPT as a financial advisor in GDPval — differences compound at scale when AI advises thousands of decisions ([One Useful Thing: Job Interview](https://www.oneusefulthing.org/p/giving-your-ai-a-job-interview)).

**Agentic work as management skill**

- Ethan Mollick ran an experiment where non-coding executive MBA students built working startup prototypes in 4 days using Claude Code and Google Antigravity — output was "an order of magnitude" further along than a full semester's work pre-AI, with most prototypes having a core feature working, not just mockups — the key variable was domain expertise enabling clear delegation, not AI expertise ([One Useful Thing: Management](https://www.oneusefulthing.org/p/management-as-ai-superpower)).
- The delegation equation: AI is worth using when (Human Baseline Time) justifies paying (AI Process Time × iterations until success); subject-matter expertise raises Probability of Success and speeds evaluation, making expertise — not prompting skill — the scarce resource ([One Useful Thing: Management](https://www.oneusefulthing.org/p/management-as-ai-superpower)).
- Every profession has existing delegation formats (PRDs, shot lists, Five Paragraph Orders, consulting engagement scopes) that work directly as AI agent prompts — all solve the same problem of externalizing intent, and all map to the same six elements: goal/why, authority limits, definition of done, required outputs, interim checkpoints, pre-submission QA ([One Useful Thing: Management](https://www.oneusefulthing.org/p/management-as-ai-superpower)).

**LLM alignment and semantic privacy research**

- SIA (Sparse Inference-time Alignment) shows model token-generation entropy reliably identifies alignment-critical junctions; steering only those 20–80% of tokens achieves superior alignment–efficiency tradeoffs vs. dense intervention, cutting compute 3–6×, integrating with Best-of-N, and for strong base models like Qwen3, 20% token intervention matches heavily post-trained instruct counterparts — dense intervention is not just wasteful but often harmful to generation quality ([arXiv:2602.21215](https://arxiv.org/abs/2602.21215)).
- SemSIEdit, an iterative Evaluator-Editor agent framework for Semantic Sensitive Information (inferring identity attributes, generating defamatory content, validating false premises), reduces semantic leakage 34.6% with 9.8% utility loss across 13 SOTA LLMs — "safety via rewriting" is an emergent large-model ability: GPT-5 achieves it through constructive expansion; smaller models (Llama-3, Gemma) resort to truncation or refusal, and GPT-5's false-information generation rate drops from 15.9% to 0% under the framework ([arXiv:2602.21496](https://arxiv.org/abs/2602.21496)).
- Agent failure analysis: failures in long-horizon agentic settings are predominantly reliability failures — compounding small off-path tool calls where one mistake increases the probability of the next — not raw capability failures; a proposed "safe & helpful" minimal benchmark would test whether models reliably follow trivially specified constraints (e.g., "send email only if asked") even with irrelevant context, where frontier models still fail ([Latent.Space](https://www.latent.space/p/wtf2025)).

**Causal discovery research**

- VCDF adds a method-agnostic validation layer to causal discovery (VAR-LiNGAM, PCMCI) that retains only edges consistent across blocked temporal partitions; improves VAR-LiNGAM F1 by 0.08–0.12 across diverse synthetic settings with up to 0.18 absolute improvement on sequences ≥1,000 timesteps — requires no modification to base algorithms, can be applied to any method outputting directed relations with effect estimates ([arXiv:2602.21381](https://arxiv.org/abs/2602.21381)).
- DyCausal (ICLR 2026 accepted) handles fully dynamic causality where both instantaneous and lagged dependencies evolve over time, using sliding convolutional windows for coarse-grained state encoding followed by linear interpolation for per-timestep refinement; a matrix-norm-based acyclic constraint avoids retraining — outperforms all evaluated baselines on synthetic and real-world datasets ([arXiv:2602.22532](https://arxiv.org/abs/2602.22532)).

**Federated learning research**

- FedVG weights client updates by validation gradient norms on a shared public dataset rather than dataset size — clients whose updates lie in flatter loss regions (smaller gradient norms) receive higher weight, better capturing generalization than accuracy alone; consistently outperforms baselines at high heterogeneity (α=0.05) across natural and medical imaging datasets and is composable with existing FL algorithms ([arXiv:2602.21399](https://arxiv.org/abs/2602.21399)).
- A Shapley-value study of FL client contributions finds client rankings across four trustworthiness dimensions (accuracy, fairness/demographic parity, noise reliability, adversarial resilience) are statistically uncorrelated — a client valuable for accuracy can be neutral or harmful for fairness or resilience, meaning performance-only evaluation systematically misidentifies valuable clients for robustness objectives ([arXiv:2602.22470](https://arxiv.org/abs/2602.22470)).

**LLM memory compression and private synthetic data**

- Latent Context Compilation compiles long contexts into portable "buffer tokens" via a disposable LoRA that is discarded post-optimization, leaving stateless KV-cache-compatible artifacts pluggable into a frozen base model — achieves 16–32× compression on Llama-3.1-8B while preserving fine-grained reasoning and general instruction-following, resolving the statefulness bottleneck that makes Test-Time Training incompatible with concurrent serving ([arXiv:2602.21221](https://arxiv.org/abs/2602.21221)).
- EPSVec (efficient private synthetic data) extracts a single direction in LLM activation space encoding the distributional gap between private and public data, sanitizes it once with differential privacy, and reuses it indefinitely at zero additional privacy cost — achieves 150% average MAUVE improvement over the next-best baseline across 4 datasets in low-data regimes; synthetic data from EPSVec matches real data for downstream BERT fine-tuning accuracy ([arXiv:2602.21218](https://arxiv.org/abs/2602.21218)).

**Agentic RL, multi-agent systems, and applied NLP**

- ARLArena identifies four sources of agentic RL training collapse (loss aggregation, IS clipping, advantage design, dynamic sampling) and distills them into SAMPO; key findings: tolerant clipping induces collapse while sequence-level clipping ensures stable improvement; incorporating environment-level information into advantage design improves both stability and performance — SAMPO achieves a 25.2% average improvement over GRPO baseline across ALFWorld, Sokoban, and other agentic tasks ([arXiv:2602.21534](https://arxiv.org/abs/2602.21534)).
- PANGAEA-GPT, a Supervisor+Worker multi-agent system for autonomous Earth science workflows on PANGAEA's 400,000+ dataset archive, demonstrated end-to-end analysis including microplastic/ocean-current coupling (Spearman ρ=−0.47, p=0.033) and a 135,678-point climate model validation against mooring observations with autonomous temporal type-mismatch resolution — nearly 90% of PANGAEA's archived datasets have never been cited in peer-reviewed literature, motivating the system ([arXiv:2602.21351](https://arxiv.org/abs/2602.21351)).
- GRASPER (ICLR 2026) addresses cold-start LLM personalization (>95% of real-world users have fewer than 2 text entries) by augmenting sparse histories with graph-based link prediction over user-item bipartite graphs and reasoning-aligned synthetic review generation — achieves >10% gains on text generation and >15% on rating prediction across Amazon, Hotel, and Stylized Feedback datasets ([arXiv:2602.21219](https://arxiv.org/abs/2602.21219)).
- Entity-enriched biomedical PLMs (BioBERT/SciBERT + scispaCy + Multiple Instance Learning with attention pooling) achieve study-level F1 of 0.82 for identifying EQ-5D health quality-of-life instrument use in abstracts — entity enrichment consistently outperforms standard fine-tuned baselines and bag-of-words approaches, enabling automated systematic review screening ([arXiv:2602.21216](https://arxiv.org/abs/2602.21216)).
- ASA-CD proposes a new paradigm combining NLP with community development via linguistic biomarkers; analysis of 18,000 annotated YouTube comments found exclusive pronouns most prevalent in negative sentiment, and 88.5% of all comments lacked inclusive pronouns — fewer than 0.4% of published work at the intersection of sociolinguistics, AI, and community development exists, per the authors' Scopus/PubMed keyword co-occurrence analysis ([arXiv:2602.21217](https://arxiv.org/abs/2602.21217)).
