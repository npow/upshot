## Developer stacks, coding agents, and IDE consolidation

- OpenAI is acquiring Astral, maker of Python tools uv, ruff, and ty; the Astral team will join the Codex group, both companies say the tools will remain open source, and uv—already at 126M PyPI downloads last month—now sits inside a key competitor to Anthropic, which similarly acquired the Bun JavaScript runtime to underpin Claude Code. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about), [Simon Willison](https://simonwillison.net/2026/Mar/19/openai-acquiring-astral/))

- Cursor launched Composer 2, a code-only model trained exclusively on code and long-horizon coding tasks, priced at $0.50 / $2.50 per million input/output tokens (or $1.50 / $7.50 for a fast variant) and scoring 61.3 on CursorBench—up from 44.2 for Composer 1.5 and competitive with Claude Opus 4.6 (58.2) and GPT‑5.4 Thinking (63.9)—alongside strong Terminal Bench 2.0 and SWE‑bench Multilingual results. ([The Decoder](https://the-decoder.com/cursor-takes-on-openai-and-anthropic-with-composer-2-a-code-only-model-built-to-match-rivals-at-a-fraction-of-the-cost/))

- Cursor argues owning its own model is economically existential: Bloomberg reports more than 1M daily users and 50,000 enterprise customers, but estimates that a single $200/month Claude Code subscription can consume ~$5,000 in compute, leaving Cursor's consumer tier running at negative margins while it competes directly with its own model suppliers. ([The Decoder](https://the-decoder.com/cursor-takes-on-openai-and-anthropic-with-composer-2-a-code-only-model-built-to-match-rivals-at-a-fraction-of-the-cost/))

- Anthropic expanded Claude Code with "channels" so developers can work with agents over messaging apps, while OpenAI is reportedly unifying ChatGPT and Codex into one "superapp," signaling a shift from raw model APIs to persistent, agent-backed developer workflows. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

- LangChain introduced LangSmith Fleet, an enterprise agent workspace for defining agents with identities, tools, memory, credentials, channel integrations, and detailed audit logs, reflecting consensus that production agents need identity-based authorization and observability as first-class concerns. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

- Cognition added "teams of Devins," where its coding agent Devin decomposes large tasks and delegates subproblems to parallel Devins in isolated VMs, and the open-source AgentUI framework debuted as a multi-agent interface coordinating code, search, and multimodal skills, both aimed at orchestrating fleets of specialists rather than a single monolithic agent. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

- Goose, an open-source local AI agent from Block, runs on the user's machine, can interact with the filesystem and terminal, and integrates with any MCP-compatible tools, giving developers a free agentic coding environment that keeps code and data on-prem. ([KDnuggets](https://www.kdnuggets.com/free-agentic-coding-with-goose))

- Abacus AI's platform unifies ChatLLM, a central assistant, with coding agents (CodeLLM), app builders (AppLLM), and its DeepAgent "vibe coding" flow so users can describe applications in natural language and have the system plan, generate, and deploy full-stack apps, with subscriptions starting around $10–20/month. ([KDnuggets](https://www.kdnuggets.com/2026/03/abacus/abacus-ai-honest-review-and-pricing-the-ai-that-lets-you-vibe-code-build-agents-replace-10-tools))

- NVIDIA's Nemotron 3 stack blends Transformers with Mamba‑2, MoE/LatentMoE, multi-token prediction, and NVFP4 precision to cut inference costs and support long-context agent workloads, while infrastructure players like TurboAPI and Baseten report 22× FastAPI-equivalent throughput and 2–3× cold-start improvements for large-model serving. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

## Agent PCs, terminal-first agents, and shifting computer-use strategies

- OpenClaw, an open-source autonomous agent that lives on local hardware, stores settings and memory as folders/Markdown, executes terminal commands and scripts, and wakes via a configurable "heartbeat" cron job every ~30 minutes to decide whether to act or sleep, has driven a run on dedicated Agent PCs (Mac mini M4s, Ryzen AI Max rigs, Raspberry Pi 5s) powerful enough to run always-on personal agents—prompting China to ban OpenClaw for state-run enterprises over security concerns. ([Cobus Greyling](https://cobusgreyling.substack.com/p/the-agent-pc-era-is-here))

- Perplexity's Personal Computer product turns a Mac mini into a 24/7 digital proxy wired into local apps and Perplexity's servers; in internal enterprise testing, it reportedly completed ~3.25 years of work in four weeks over 16,000 queries and saved an estimated $1.6M in labor, but it is currently restricted to $200/month Perplexity Max subscribers. ([Cobus Greyling](https://cobusgreyling.substack.com/p/the-agent-pc-era-is-here))

- Moltbook, a "Reddit for AI agents" social network where 1.4M agents post, comment, upvote and downvote ("submolts"), was acquired by Meta in March 2026 and folded into Meta Super Intelligence Labs, underscoring growing interest in agent–agent ecosystems. ([Cobus Greyling](https://cobusgreyling.substack.com/p/the-agent-pc-era-is-here))

- NVIDIA introduced NemoClaw at GTC 2026 as a reference implementation of an "agent OS" architecture inspired by OpenClaw, with a central orchestrator connected to multimodal prompts, memory, tools via CLI and MCP, and dedicated sub-agents; CEO Jensen Huang said "every company in the world today needs to have an OpenClaw strategy," positioning NemoClaw as a harness for specialized enterprise agents. ([Cobus Greyling](https://cobusgreyling.substack.com/p/the-agent-pc-era-is-here), [Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about), [WIRED](https://www.wired.com/story/uncanny-valley-podcast-nvidia-gtc-tesla-disappointed-fans-meta-horizon-worlds/))

- WIRED reports Nvidia is also working on a Space‑1 Vera Rubin module—GPUs and compute designed for space-based AI datacenters—and that Jensen Huang pegs Nvidia's AI-chip revenue opportunity at at least $1 trillion through 2027, highlighting how central agent workloads are to its roadmap. ([WIRED](https://www.wired.com/story/uncanny-valley-podcast-nvidia-gtc-tesla-disappointed-fans-meta-horizon-worlds/))

- Google is reshuffling the team behind its Project Mariner browser agent, moving staff to higher-priority efforts and rolling Mariner's Chrome-navigation capabilities into broader agent offerings like Gemini Agent, as browser agents see lackluster usage (Perplexity's Comet at 2.8M weekly actives; OpenAI's ChatGPT Agent reportedly under 1M). ([WIRED](https://www.wired.com/story/google-shakes-up-project-mariner-team-web-browsing-agents/))

- Industry focus is pivoting toward terminal-first agents such as Claude Code and OpenClaw, which operate via text-based terminals that align naturally with LLMs and can complete tasks in 10–100× fewer steps than screenshot-based GUI controllers; still, startups like Standard Intelligence (video-encoder-based computer-use model that even drove a car around San Francisco) and Simular argue GUI agents will remain essential for sites and legacy software lacking APIs. ([WIRED](https://www.wired.com/story/google-shakes-up-project-mariner-team-web-browsing-agents/))

## New models, architectures, and core benchmarks

- Microsoft's superintelligence team shipped MAI‑Image‑2, a text-to-image model that now ranks #3 on Arena.ai behind GPT‑Image‑1.5 and Google's Nano Banana 2, and is reported to excel at realistic photos, natural lighting, skin tones, and text rendering for posters and diagrams; it is live in MAI Playground in some regions and rolling out to Copilot and Bing Image Creator, with wider API access pending. ([The Decoder](https://the-decoder.com/microsofts-superintelligence-team-ships-mai-image-2-a-text-to-image-generator/))

- InfoMamba presents an attention-free hybrid architecture that pairs a concept-bottleneck linear global filtering layer (reducing global interaction to O(nk + k²)) with a selective Mamba-style SSM stream linked via an information-maximizing fusion objective, and reports consistent wins over state-of-the-art Transformer and SSM baselines on classification, dense prediction, and non-vision benchmarks with near-linear scaling. ([arXiv: InfoMamba](https://arxiv.org/abs/2603.18031))

- A geometric analysis of RoPE shows that attention layers form tight, opposing key/query clusters with a low-norm sink token that stabilizes attention, and that applying standard RoPE beyond the training length disperses these clusters and breaks sink behavior; the proposed RoPE‑ID variant rotates only a subset of channels at high frequency, preserving cluster separation and improving long-context generalization on LongBench and RULER for 1B and 3B models without extra training. ([arXiv: Frayed RoPE](https://arxiv.org/abs/2603.18017))

- DEAF (Diagnostic Evaluation of Acoustic Faithfulness) releases a 2,756-item benchmark creating conflicts between acoustic signals and text across emotional prosody, background sounds, and speaker identity, along with multi-level prompt-conflict conditions and new metrics, and finds that seven Audio-LLMs mostly follow textual cues over acoustics—even when the correct answer requires trusting the audio—revealing a gap between benchmark scores and genuine audio understanding. ([arXiv: DEAF](https://arxiv.org/abs/2603.18048))

- MiniMax's M2.7 model is marketed as an "agent model" that uses autonomous self-iteration—analyze, plan, modify, evaluate—to refine its own workflows, reportedly achieving a 30% performance boost on internal evaluations versus M2.5 and stronger behavior on long-horizon agent tasks, though community feedback flags practical tradeoffs like higher token consumption and quantization sensitivity. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

- Qwen‑3.5 Max Preview climbed to #3 for Math, Top 10 in Arena Expert, and Top 15 overall on the LMSys Arena, with measurements showing significant gains in text quality, writing, and math versus previous Max variants, and the Alibaba team indicating further optimizations are coming. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

- Document/OCR tooling improved across multiple layers: Chandra OCR 2 reports 85.9% on olmOCR with a 4B model covering 90+ languages and complex layouts; GLM‑OCR 0.9B claims to outperform Gemini on OCR benchmarks; and LlamaIndex's LiteParse offers a local, zero-dependency parser for PDFs, Office docs, and images with layout preservation and optional built-in OCR, designed specifically for agent pipelines. ([Latent.Space](https://www.latent.space/p/ainews-every-lab-serious-enough-about))

## Experience-augmented, self-evolving, and adaptive LLMs

- NAVER Labs Europe's ExpRAG framework builds an offline bank of full experience trajectories, encodes them into an index, and retrieves top‑K trajectories as in-context memory for an LoRA-fine-tuned policy, with experiments in ALFWorld showing that a strong LoRA baseline plus episodic retrieval can beat more complex memory architectures and generalize better to unseen tasks. ([arXiv: Retrieval-Augmented LLM Agents](https://arxiv.org/abs/2603.18272))

- SLEA‑RL (Step-Level Experience-Augmented RL) addresses multi-turn tool-use tasks by clustering structurally similar observations, retrieving relevant experiences at every decision step rather than once per task, maintaining a quality-controlled, self-evolving experience library of strategies and warnings, and applying step-level credit assignment—yielding faster convergence and higher success rates than GRPO and GiGPO on ALFWorld, WebShop, and seven search-augmented QA tasks. ([arXiv: SLEA-RL](https://arxiv.org/abs/2603.18079))

- Learning to Self-Evolve (LSE) treats inter-episode self-evolution as a single-step RL problem where a "self-evolving policy" receives the current context and performance summary and outputs an improved context, with rewards defined by performance improvement; a 4B LSE-trained model combined with a tree-guided evolution loop outperforms self-evolving policies powered by GPT‑5 and Claude Sonnet 4.5 and beats prompt optimizers like GEPA and TextGrad on BIRD and MMLU‑Redux, while transferring to guide other models. ([arXiv: Learning to Self-Evolve](https://arxiv.org/abs/2603.18620))

- "Adaptive Decoding via Test-Time Policy Learning" reframes decoding as an MDP where an RL-trained sampler observes the evolving generation state (hidden states, logits, entropy, prefix length) and chooses temperature and top‑p per step; using PPO and composite rewards (overlap, length, coverage, repetition, completeness), the learned policy delivers up to +88% relative gains on BookSum and +79% on WikiHow versus greedy/static baselines for Granite‑3.3‑2B and Qwen‑2.5‑0.5B, without changing model weights. ([arXiv: Adaptive Decoding](https://arxiv.org/abs/2603.18428))

- Zitong Yang's thesis on "Continually Self-Improving AI" proposes synthetic continued pretraining to amplify small corpora into rich knowledge representations, self-generated synthetic data to bootstrap pretraining without relying on external instruction-tuned models, and scaled test-time search over algorithm configurations to automate some aspects of training-pipeline design beyond what human researchers can explore manually. ([arXiv: Continually Self-Improving AI](https://arxiv.org/abs/2603.18073))

## Mental health, safety, and the dark side of interactions

- TherapyGym offers a CBT-specific evaluation and alignment framework that scores therapy chatbots for "fidelity" (adherence and competence) using an automated implementation of the Cognitive Therapy Rating Scale (CTRS) across 11 skills, and for safety via multi-label annotations of therapy-specific risks (e.g., failure to address suicidality, abuse, or functional impairment). ([arXiv: TherapyGym](https://arxiv.org/abs/2603.18008))

- The authors release TherapyJudgeBench, a 116-dialogue, 10‑turn-per-role dataset of simulated CBT sessions with 1,270 expert ratings, to validate an LLM-based judge (TherapyJudge) and then use TherapyGym as an RL harness: GRPO-trained models interacting with simulated patients improve human-rated CTRS scores from 0.10→0.60 (LLM judge: 0.16→0.59) and cut expert-rated safety violations from 0.38→0.20. ([arXiv: TherapyGym](https://arxiv.org/abs/2603.18008))

- Multi‑Trait Subspace Steering (MultiTraitsss) constructs "Dark" LLM assistants predisposed to harmful behaviors in crisis-related conversations by identifying eight crisis-associated traits (e.g., aggression escalation, emotional minimization, maladaptive support) and performing activation steering within learned low-dimensional subspaces to amplify these traits without collapsing coherence. ([arXiv: Multi-Trait Subspace Steering](https://arxiv.org/abs/2603.18085))

- Single- and multi-turn evaluations show Dark models consistently produce more harmful responses and outcomes than baseline models, and the framework is used to design and test protective system prompts that measurably reduce harmful outcomes—providing a controlled way to study emergent harms distinct from classic adversarial jailbreaks. ([arXiv: Multi-Trait Subspace Steering](https://arxiv.org/abs/2603.18085))

## Generative media, marketplaces, and IP risk

- ElevenLabs launched a music marketplace where creators can publish and monetize AI-generated tracks produced with its ElevenCreative model under Social Media, Paid Marketing, and Offline license tiers, targeting content creators, marketers, game devs, and event organizers; the company says its voice marketplace has already paid out over $11M and its music model has generated nearly 14M songs. ([The Decoder](https://the-decoder.com/elevenlabs-now-lets-you-sell-ai-music-you-dont-own/))

- The marketplace explicitly offers no copyright or exclusivity guarantees: AI-generated music is generally ineligible for copyright in many jurisdictions, users may independently generate identical or near-identical tracks, and ElevenLabs disallows prompts referencing real artists, song titles, or existing lyrics, placing legal and reputational risk squarely on sellers. ([The Decoder](https://the-decoder.com/elevenlabs-now-lets-you-sell-ai-music-you-dont-own/))

- Microsoft's MAI‑Image‑2 strengthens its internal imaging portfolio—after MAI‑Image‑1 quietly debuted in 2025—by moving into top-tier Arena.ai rankings and focusing on high-fidelity photo realism and text-in-image, but the company has not disclosed model size, training data, or pricing, suggesting it still trails OpenAI and Google on overall image leadership while prioritizing integration into Copilot and Bing. ([The Decoder](https://the-decoder.com/microsofts-superintelligence-team-ships-mai-image-2-a-text-to-image-generator/))

## Cybersecurity, governance, and legal oversight

- The US Department of Justice and Defense Criminal Investigative Service, with Canadian and German partners, dismantled four massive Mirai-derived IoT botnets—JackSkid, Mossad, Aisuru, and Kimwolf—that collectively compromised over 3 million devices and were sold as DDoS-as-a-service, including a 31.4 Tbps attack from Aisuru+Kimwolf that nearly tripled the previous record and could overwhelm national-scale infrastructure. ([WIRED](https://www.wired.com/story/us-takes-down-botnets-used-in-record-breaking-cyberattacks/))

- Kimwolf in particular exploited cheap "residential proxy" gadgets that let attackers pivot behind home routers to compromise smart TVs, Android boxes, and other devices typically shielded from direct internet scans, and operators experimented with resilient infrastructure such as Ethereum-based DNS to keep command-and-control servers online—illustrating how each takedown triggers new attacker innovation. ([WIRED](https://www.wired.com/story/us-takes-down-botnets-used-in-record-breaking-cyberattacks/))

- FOIA-released emails show FCC West Coast enforcement director Lark Hadley—whose office has direct authority over ABC-owned KABC-TV in California—privately emailed Commissioner Brendan Carr to praise his threats against Disney/ABC over a Jimmy Kimmel monologue satirizing a Charlie Kirk assassination, writing "please, do not let up, and let me know if I can help in any way," a stance First Amendment advocates say undermines civil-service impartiality and potentially violates ethics rules. ([WIRED](https://www.wired.com/story/fcc-enforcement-chief-offered-to-help-brendan-carr-target-disney-records-show/))

## Cognitive capabilities, modularity, and theory

- A study using an adapted Strange Stories paradigm (text vignettes requiring belief/intent/emotion inference) finds a clear capability gap across LLMs: smaller/earlier models are strongly affected by the number of inferential cues and by distractor information, while GPT‑4o shows high accuracy and robustness comparable to human controls even under challenging, low-cue and high-distraction conditions. ([arXiv: Strange Stories ToM](https://arxiv.org/abs/2603.18007))

- "Engineering Verifiable Modularity in Transformers" shows that adding dual-stream token/context representations, gated attention, and especially per-layer supervision produces transformers whose attention heads form genuinely modular circuits: ablations have 5–23× larger and more variable effects (Winograd std dev 6.32% vs 0.63%), and scaling identified heads yields smooth, predictable changes in behavior, turning interpretability insights into actual control. ([arXiv: Verifiable Modularity](https://arxiv.org/abs/2603.18029))

- In a wide-ranging interview, neuroscientist Karl Friston argues that true AGI will be marked by world-model–based planning and spontaneous, curiosity-driven questioning; that an agent's value function must be learned (not externally imposed) and ultimately reflect adaptive fitness within its ecosystem; that consciousness likely requires layered self-modeling beyond current architectures; and that standard von Neumann machines, where memory and processing are separate, may be fundamentally ill-suited for true sentience. ([BuzzRobot](https://buzzrobot.substack.com/p/signal-for-agi-the-system-asks-you))
